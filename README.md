
# GSoC 2027 Preparation Roadmap 🚀

My personal roadmap for learning open-source development,
researching GSoC organizations, and preparing meaningful contributions.

## 🎯 Goals
- Strengthen Python and Git fundamentals.
- Research GSoC organizations from 2022–2026.
- Identify projects related to AI/ML and Python.
- Learn testing, debugging, and code review.
- Work toward three genuine upstream pull requests.
- Prepare a proposal aligned with a participating organization's needs.

## 📚 Learning Checklist
- [ ] Python fundamentals
- [ ] Git branches, commits, and merge conflicts
- [ ] GitHub issues and pull requests
- [ ] pytest and automated testing
- [ ] Reading an unfamiliar codebase
- [ ] Writing useful documentation
- [ ] Reproducing and fixing a bug

## 🔎 Organization Research

For each potential organization, record:
- Organization name
- GSoC participation year
- Official website and repository
- Relevant project ideas
- Contributor guide
- Beginner-friendly issues
- Communication channels
- Application requirements

## 🤖 Areas of Interest
- Python libraries and developer tools
- AI/ML infrastructure and model deployment
- Data processing and scientific computing
- Testing and developer productivity
